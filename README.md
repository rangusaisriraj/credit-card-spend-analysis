# 💳 Credit Card Spend Analysis (SQL Project)

This SQL project explores credit card transaction data from India to identify spending patterns, city-level trends, gender behavior, and performance metrics.

---

## 🔍 Key Questions Answered

1. Top 5 cities with highest spends and their % contribution  
2. Highest spend month per card type  
3. When each card type hits ₹10,00,000 cumulative spend  
4. City with lowest spend % for Gold card  
5. City-wise highest and lowest expense types  
6. Female spend % by expense type  
7. Card + expense type combo with max MoM growth in Jan 2014  
8. Most efficient city on weekends (spend-to-txn ratio)  
9. Fastest city to reach 500 transactions
